# Калькулятор НДС

Офлайн-приложение для расчёта НДС: начислить сверху или выделить из суммы.
Без интернета, без рекламы, данные остаются на устройстве.

## Что умеет

- Режимы «Начислить НДС» и «Выделить НДС».
- Ставки 20%, 10%, 7%, 5%, 0% и своя ставка.
- Итоги: сумма без НДС, НДС, сумма с НДС (округление до копеек).
- Копирование результата в буфер обмена.
- История последних расчётов (нажмите на запись, чтобы подставить сумму).

## Файлы

| Файл | Назначение |
|---|---|
| `NDS-calculator.apk` | Готовое Android-приложение (33 КБ) |

## Установка APK на Android

1. Перекиньте `NDS-calculator.apk` на телефон (кабель, облако, Telegram «Избранное»).
2. Откройте файл в проводнике телефона.
3. Разрешите установку из этого источника, когда система спросит.
4. Приложение появится в списке под названием «Калькулятор НДС».

Характеристики сборки: `ru.multitool.nds`, версия 1.0, minSdk 21 (Android 5.0+),
targetSdk 34. Подпись — debugging-ключ, поэтому Google Play такую сборку не примет;
для распространения через магазин нужен свой релизный ключ и подпись им.

APK — это WebView-обёртка: интерфейс (тот же `index.html`) лежит внутри APK в `assets/`,
поэтому приложение работает полностью офлайн и не запрашивает интернет-разрешений.

## Как открыть на компьютере

Двойной клик по `index.html` — откроется в браузере и сразу работает.

## Как поставить на Android

Вариант 1, через локальный сервер (даёт полноценную установку как приложение):

1. Установите на ПК Python или Node — либо используйте любой статический сервер.
2. В папке `vat-calculator` запустите: `python -m http.server 8000`
3. Телефон и ПК в одной сети Wi-Fi. На телефоне откройте `http://<IP-ПК>:8000`
4. Меню Chrome → «Добавить на главный экран» / «Установить приложение».

Вариант 2, без сервера: скопируйте `index.html` на телефон и откройте файл в Chrome
(«Файлы» → Открыть с помощью → Chrome). Приложение работает, но иконки на рабочем столе не будет.

## Точность расчёта

Округление до копеек (2 знака) после каждого действия, как в бухгалтерской практике:
- начисление: `НДС = сумма × ставка / 100`, `итого = сумма + НДС`;
- выделение: `НДС = сумма × ставка / (100 + ставка)`.
